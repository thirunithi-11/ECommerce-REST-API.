# E-Commerce Management System

## Project Overview
A full-stack E-Commerce Management System developed using Spring Boot and MySQL. It provides REST APIs to manage users, products, categories, carts, orders, payments, deliveries, inventory, invoices, reviews, and wishlists.

## Technologies Used
- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- REST API
- Postman
- React JS

## Main Modules
1. User Management
2. Product Management
3. Category Management
4. Cart Management
5. Order Management
6. Payment Management
7. Delivery Management
8. Inventory Management
9. Invoice Management
10. Review Management
11. Wishlist Management

## API Testing
All REST API modules were tested using Postman.

MySQL
